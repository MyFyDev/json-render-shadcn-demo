# @json-render/shadcn component gallery

Each component has a **json-render/catalog/{component}** story (catalog props for the AI demo) and, when a matching primitive exists under `components/ui`, **shadcn/ui/{component}/\*** stories for every export with controls aligned to the [shadcn/ui docs](https://ui.shadcn.com/docs/components).

**Button** and **Card** catalog schemas are extended in `lib/catalog/definitions/` and rendered with local `components/ui` via `lib/registry/components/`.

## Components (36)

| Category | Components |
| -------- | ---------- |
| Layout | Card, Stack, Grid, Separator |
| Navigation | Tabs, Accordion, Collapsible, Pagination |
| Overlay | Dialog, Drawer, Tooltip, Popover |
| Content | Heading, Text, Image, Avatar, Badge, Alert, Carousel, Table |
| Feedback | Progress, Skeleton, Spinner |
| Input | Button, Link, Input, Textarea, Select, Checkbox, Radio, Switch, Slider, Toggle, ToggleGroup, ButtonGroup, DropdownMenu |

Dialog and Drawer stories open by default via `openPath` state (`/story/dialogOpen`, `/story/drawerOpen`).
